# Black Mamba — 실행 데모 시나리오

> 발표 시 라이브 데모 또는 스크린샷 첨부용

---

## 시나리오 1: 강남역 → 홍대입구 (도심 통근)

**의도:** 가장 일반적인 통근 패턴. 대중교통 vs 따릉이 혼합 비교.

```
출발: 강남역 (37.4979, 127.0276)
도착: 홍대입구 (37.5573, 126.9246)
모드: OPTIMAL / RELIABILITY
```

**기대 결과:**
- 대중교통만(2호선 직행) 약 25~30분
- 따릉이 라스트마일 조합 시 2~5분 절감 가능
- 신뢰도 배지: 따릉이 가용성에 따라 "대여 여유 적음" or "안정적"

---

## 시나리오 2: 수서역 → 이태원 (외곽 → 시내)

**의도:** 퍼스트마일이 유의미한 케이스. 지하철역까지 도보가 길어 개인 PM이 효과적.

```
출발: 수서역 (37.4872, 127.1016)
도착: 이태원역 (37.5345, 126.9946)
모드: SPECIFIC / PERSONAL_EBIKE + TIME_PRIORITY
```

**기대 결과:**
- 대중교통만 약 40~50분
- 개인 전기자전거 퍼스트마일 시 5~10분 절감
- 추천 이유: "시간 X분 절감", "접근 도보 짧음"

---

## 시나리오 3: 여의도공원 → 서울숲 (중거리, 다양한 이동수단)

**의도:** 패턴 E(이동수단만) 가능 거리. 따릉이 vs 개인 킥보드 vs 대중교통 비교.

```
출발: 여의도공원 (37.5264, 126.9343)
도착: 서울숲 (37.5445, 127.0374)
모드: OPTIMAL / TIME_PRIORITY
```

**기대 결과:**
- 대중교통 35~40분 (환승 1~2회)
- 개인 킥보드 직접 이동 약 25~30분 (MOBILITY_ONLY)
- 따릉이 + 지하철 조합 가능
- 경로 타입 다양성 확인 (TRANSIT_ONLY, TRANSIT_WITH_BIKE, MOBILITY_ONLY 모두 등장)

---

## 시나리오 4: 단거리 (700m 이내) — 에러 케이스

**의도:** 입력값 검증 시연.

```
출발: 강남역 (37.4979, 127.0276)
도착: 강남역 근처 (37.4985, 127.0280)
```

**기대 결과:** 400 응답 + "출발지와 목적지가 700m 이내" 메시지

## 데모 포인트 (발표 시 강조)

### 1. 추천 이유 (Recommendation Reasons)
- "시간 5분 절감" / "도보 300m 감소" / "반납 정류소 확인"
- 단순 ETA가 아닌 **설명 가능한 추천**

### 2. 리스크 배지 (Risk Badges)
- "공유수단 의존" / "대여 여유 적음" / "접근 도보 김"
- 사용자가 경로 리스크를 인지하고 선택할 수 있음

### 3. 이중 추천 축 비교
- 같은 출발/도착으로 RELIABILITY vs TIME_PRIORITY 결과 비교
- RELIABILITY: 대중교통 유지 경향
- TIME_PRIORITY: 혼합 경로 추천 경향

### 4. Swagger UI 시연
- `http://localhost:8081/swagger-ui.html`
- 파라미터 example 값 포함 → Try it out으로 즉시 실행

### 5. Actuator 메트릭 시연
- `http://localhost:8081/actuator/metrics/navigation.cache.total`
- 캐시 hit/miss 비율 실시간 확인
