# 신뢰도 스코어링 산정 근거

> 작성일: 2026-03-23
> 목적: 각 스코어링 가중치와 임계값이 어떤 근거로 산정되었는지 문서화

---

## 1. 전체 스코어링 공식

```
totalScore = (시간 × W₁) + (환승 × W₂) + (비용 × W₃) + (도보 × W₄) + (접근도보 × W₅) + (신뢰도 × W₆)
```

각 항목은 `1.0 - min(실제값 / 최대기대값, 1.0)` 으로 정규화 (0.0 ~ 1.0, 높을수록 좋음)

## 4. 신뢰도 페널티 산정 근거

신뢰도 점수는 **1.0에서 시작, 조건 충족 시 감산** 방식.

### 4-1. 반납 정류소 미확인 (weakDropoff)

| | RELIABILITY | TIME_PRIORITY |
|--|------------|---------------|
| 페널티 | **-0.35** | -0.20 |
| 조건 | 따릉이 leg에 반납 정류소 정보 없음 |

**근거:** 가장 큰 페널티. 따릉이는 **스테이션 기반** 서비스라 반납 정류소가 없으면 경로 자체가 성립 불가. 목적지 근처에 반납 가능한 빈 거치대가 확인되지 않으면 사용자가 반납 불가 → 추가 요금 + 시간 낭비. 서울시 따릉이 정류소당 평균 거치대 약 16.7대이지만, 출퇴근 시간대 인기 정류소는 만차 빈발.

**검증:** 0.35는 전체 신뢰도의 35%를 깎는 것. 신뢰도 가중치 0.15 기준 총 점수에 약 0.05점(5%) 영향. 경로 추천 순위 1~2단계 하락 효과. **적정**.

---

### 4-2. 대여 가능 대수 부족 (lowAvailability)

| | RELIABILITY | TIME_PRIORITY |
|--|------------|---------------|
| 페널티 | **-0.15** | -0.08 |
| 조건 | 따릉이 가용 대수 ≤ 2대 |

**근거:** 서울시 따릉이 정류소당 평균 약 16.7대 (45,000대 ÷ 2,700개소). 2대 이하는 **하위 12% 수준**이며, 사용자가 도착했을 때 이미 대여됐을 확률 높음. 특히 출퇴근 시간대 회전율 고려 시 2대는 5~10분 내 소진 가능.

**임계값 ≤ 2대 검증:**
- 0대: 이미 없음 → 경로 자체 제외 (애초에 후보에 안 잡힘)
- 1~2대: 도착 시 없을 확률 높음 → 페널티
- 3대 이상: 합리적 기대 가능

**검증:** 0.15 × 0.15(가중치) = 약 0.02점. 경로 순위 미세 조정 효과. **적정**.

---

### 4-3. 배터리 부족 (lowBattery)

| | RELIABILITY | TIME_PRIORITY |
|--|------------|---------------|
| 페널티 | **-0.15** | -0.08 |
| 조건 | 킥보드 배터리 < 30% |

**근거:** 공유 킥보드 평균 이용거리 1.5km, 이용시간 9.4분. 전동킥보드 배터리 100% 기준 주행거리 약 20~25km. 30% 잔량이면 약 6~7.5km 가능. 겉으로는 충분해 보이지만, **배터리 잔량 표시의 부정확성** + **오르막 급소모** + **추운 날씨 급감** 고려 시 30% 미만은 리스크.

**현재 이슈:** `lowBattery` 페널티가 `lowAvailability`와 동일 값(0.15) 사용. 이는 **의도적 설계** — 둘 다 "도착했는데 못 타는" 동일 리스크 카테고리.

**검증:** **적정**. 배터리 30% 기준도 업계 기준(운영사 수거 기준 15~20%)보다 보수적이라 안전.

---

### 4-4. 공유수단 의존 (sharedMobility)

| | RELIABILITY | TIME_PRIORITY |
|--|------------|---------------|
| 페널티 | **-0.10** | -0.04 |
| 조건 | 운영사명 ≠ "개인" (공유 이동수단 포함 경로) |

**근거:** 공유 이동수단은 개인 소유 대비 고유 리스크 존재:
- 재배치로 인한 위치 변동
- 고장/파손 상태
- 사용 중 반환 지연
- 성수기/비수기 공급 불균형

**검증:** 0.10은 가장 약한 페널티 중 하나. "공유라서 약간 불안" 수준. **적정**. 단, PERSONAL_EBIKE/PERSONAL_KICKBOARD가 도입되면서 이 페널티는 `DDAREUNGI`와 `KICKBOARD_SHARED`에만 적용됨 — 개인 수단은 면제.

---

### 4-5. 대여소 접근 거리 (weakPickupAccess)

| | RELIABILITY | TIME_PRIORITY |
|--|------------|---------------|
| 페널티 | **-0.12** | -0.08 |
| 조건 | 가장 가까운 대여소까지 ≥ 900m |

**근거:** 900m = 도보 약 12분. 이미 12분을 걸어서 이동수단을 픽업해야 하면 혼합 경로의 시간 절약 효과가 크게 감소. 서울시 평균 대중교통 접근 거리 580m(8.69분) 대비 1.5배 이상.

**검증:** **적정**. 900m는 "멀긴 하지만 갈 수는 있는" 경계선.

---

### 4-6. 허브 우회 거리 (weakHubDetour)

| | RELIABILITY | TIME_PRIORITY |
|--|------------|---------------|
| 페널티 | **-0.08** | -0.04 |
| 조건 | 환승 허브가 기준 경로에서 ≥ 2,000m 벗어남 |

**근거:** 2,000m 우회는 자전거(15km/h) 기준 약 8분, 킥보드(20km/h) 기준 약 6분 추가. 이미 시간 점수에 반영되지만 **"왜 이렇게 돌아가지?"라는 사용자 불만** 방지용 추가 페널티.

**검증:** 0.08은 가장 작은 페널티. 우회는 시간 점수에도 이미 반영되므로 이중 페널티를 방지하기 위해 낮게 설정. **적정**.

---

### 4-7. 접근 도보 거리 (accessWalkPenalty)

| | RELIABILITY | TIME_PRIORITY |
|--|------------|---------------|
| 페널티 | **-0.15** | -0.08 |
| 임계값 | ≥ 300m | ≥ 420m |

**근거:** 접근 도보 = 지하철역/버스정류장 → 이동수단 픽업 지점까지의 도보. 일반 도보와 달리 **목적지에 도착하기 위한 도보가 아니라 이동수단을 타기 위한 추가 도보**라서 사용자 체감 불만이 더 큼.

**임계값 검증:**
- RELIABILITY 300m (도보 약 4분): 지하철 출구에서 따릉이까지 4분 이상 걸으면 불편
- TIME_PRIORITY 420m (도보 약 5.5분): 시간 우선이면 5분 정도는 감수

**검증:** **적정**. 300m/420m는 서울 지하철역 출구 밀집 지역에서 따릉이까지의 실거리 분포(100~500m)를 고려한 값.

## 5. 모드 간 페널티 경감 비율

TIME_PRIORITY는 RELIABILITY 대비 **40~60% 감경**:

| 페널티 | RELIABILITY | TIME_PRIORITY | 감경률 |
|--------|-----------|---------------|--------|
| 반납 미확인 | 0.35 | 0.20 | -43% |
| 대여 부족 | 0.15 | 0.08 | -47% |
| 배터리 낮음 | 0.15 | 0.08 | -47% |
| 공유수단 | 0.10 | 0.04 | -60% |
| 접근 거리 | 0.15 | 0.08 | -47% |
| 대여소 접근 | 0.12 | 0.08 | -33% |
| 허브 우회 | 0.08 | 0.04 | -50% |

**근거:** 일률적으로 약 50% 감경. "시간 우선 사용자는 리스크를 절반 정도 감수한다"는 직관적 설계.

## 6. 스코어링 검증 시나리오

### 시나리오 A: 이상적인 혼합 경로 (RELIABILITY 모드)

```
경로: 지하철 20분 → 도보 150m → 따릉이 10분 (가용 5대, 반납 확인됨)
시간: 30분, 환승: 0, 비용: 2,400원, 도보: 150m, 접근도보: 150m

시간 점수:     1.0 - (30/90) = 0.67
환승 점수:     1.0 - (0/5)  = 1.00
비용 점수:     1.0 - (2400/5000) = 0.52
도보 점수:     1.0 - (150/1500) = 0.90
접근도보 점수: 1.0 - (150/600) = 0.75
신뢰도 점수:   1.0 (페널티 없음)

총점 = 0.67×0.4 + 1.0×0.15 + 0.52×0.1 + 0.90×0.1 + 0.75×0.1 + 1.0×0.15
     = 0.268 + 0.15 + 0.052 + 0.09 + 0.075 + 0.15
     = 0.785 ← 높은 점수
```

### 시나리오 B: 리스크 있는 혼합 경로

```
경로: 버스 15분 → 도보 400m → 따릉이 8분 (가용 1대, 반납 미확인)
시간: 23분, 환승: 0, 비용: 2,400원, 도보: 400m, 접근도보: 400m

시간 점수:     1.0 - (23/90) = 0.74
환승 점수:     1.0 - (0/5)  = 1.00
비용 점수:     1.0 - (2400/5000) = 0.52
도보 점수:     1.0 - (400/1500) = 0.73
접근도보 점수: 1.0 - (400/600) = 0.33
신뢰도 점수:   1.0 - 0.35(반납) - 0.15(가용) - 0.10(공유) - 0.15(접근≥300m) = 0.25

총점 = 0.74×0.4 + 1.0×0.15 + 0.52×0.1 + 0.73×0.1 + 0.33×0.1 + 0.25×0.15
     = 0.296 + 0.15 + 0.052 + 0.073 + 0.033 + 0.0375
     = 0.641 ← 시나리오 A보다 낮음. 빠르지만 리스크 반영됨
```

### 시나리오 C: 대중교통만 (기준선)

```
경로: 지하철 → 버스 환승 → 도보
시간: 40분, 환승: 1, 비용: 1,500원, 도보: 500m, 접근도보: 0m

시간 점수:     1.0 - (40/90) = 0.56
환승 점수:     1.0 - (1/5)  = 0.80
비용 점수:     1.0 - (1500/5000) = 0.70
도보 점수:     1.0 - (500/1500) = 0.67
접근도보 점수: 1.0 - (0/600) = 1.00
신뢰도 점수:   1.0 (페널티 없음 — 공유수단 미사용)

총점 = 0.56×0.4 + 0.80×0.15 + 0.70×0.1 + 0.67×0.1 + 1.0×0.1 + 1.0×0.15
     = 0.224 + 0.12 + 0.07 + 0.067 + 0.10 + 0.15
     = 0.731
```

### 시나리오 검증 결과

```
시나리오 A (이상적 혼합): 0.785  ← 가장 높음 ✓
시나리오 C (대중교통만):  0.731  ← 안정적이지만 느림
시나리오 B (리스크 혼합): 0.641  ← 빠르지만 신뢰도 낮음

순위: A > C > B
→ 빠르지만 반납 미확인 + 가용 1대 경로가 대중교통보다 낮게 평가됨. 의도한 설계 동작.
```

## 7. 알려진 한계

1. **가중치는 경험적 설정** — AHP 기반 사용자 설문 데이터로 보정하면 더 정확해짐
2. **시간대별 가중치 미반영** — 출퇴근 시간대에는 따릉이 가용성 리스크가 높아지지만 현재 고정 가중치
3. **날씨 미반영** — 비/눈 오는 날 자전거/킥보드 경로의 신뢰도가 급감하지만 현재 미반영
4. **이동수단별 서비스 품질 미구분** — 공유수단 페널티가 운영사 무관하게 동일
